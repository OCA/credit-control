1. Go to *Invoicing > Customers > Finance Charges*.
2. Set the date to charge through, up to today, and click **Recalculate** if you
   changed it.
3. Tick the invoices to charge, or use **Select All** / **Select None**. Select
   All leaves rows in red unticked: those customers have an unapplied payment
   or credit, or a payment in process, so check them first.
4. Click **Create Draft Charges**, then review and post the draft invoices.

Each invoice remembers the period already billed, so the next charge starts
where the last one ended. Cancelling or deleting the most recent draft charge
makes its period available again. A credit note does not.
